# pubspec links point to the zukkoai repo

## What
`repository` and `issue_tracker` in pubspec.yaml now point to https://github.com/zukkoai/zukko-chat-flutter.

## Why
Owner chose the zukkoai GitHub repo as the package's home for pub.dev and automated publishing. The published pubspec of a version cannot change later, so this is set before the first release.
