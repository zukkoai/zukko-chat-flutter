# Release 1.0.1

## What
Version bumped to 1.0.1 with a CHANGELOG entry. No code changes.

## Why
pub.dev shows the README from the published archive. 1.0.0 was published (07:42) before the badge fix commit (07:48), so its README still had the large `height="56"` logos, which pub.dev's CSS ignores. Published versions are immutable, so a new version is needed.
