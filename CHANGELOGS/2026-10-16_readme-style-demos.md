# README style demos

## What
Added a "Styles" section at the top of README.md: for each of the 3 chat styles a looping GIF demo (`assets/videos/zukko-chat-<style>.gif`, 300 px, 12 fps), a link to the full mp4, and a short compilable example screen. Added `assets/videos/` to `.pubignore`.

## Why
GitHub and pub.dev do not play repo `<video>` files, so GIFs are used. Demo media must not bloat the pub package.
