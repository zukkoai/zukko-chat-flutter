# HTTPS-only: remove allowInsecure

## What
- Removed `allowInsecure` from `ZukkoChatOptions`, `ZukkoChatClient.create`, `ZukkoChatClientFactory` and the example demo client.
- `validateBaseUrl` accepts only `https`; any `http` URL (including localhost, 127.0.0.1, ::1, 10.0.2.2) throws `ArgumentError`. The socket URL is always `wss://`.
- Tests: `FakeChatServer` is now a real TLS server with a self-signed cert generated by `openssl` at test start and trusted only inside the test process, so tests still run the real client with no insecure option. Loopback/allowInsecure tests became "http is rejected" tests.

## Why
Owner decision: the SDK talks to the server only over https/wss, with no plain-http escape hatch for apps.

## Also removed: public clientFactory
- `ZukkoChat.clientFactory`, `ZukkoChatView.clientFactory` and the `ZukkoChatClientFactory` export are gone; nothing test-only is public.
- Widget tests inject a fake client through `debugClientFactory` (`@visibleForTesting` top-level in `lib/src/ui/chat/zukko_chat_view.dart`, not exported). `ZukkoChatController(clientFactory:)` stays: the controller is internal.
- The example's offline demo client needed that parameter, so it was removed; the example now only has the live chat.
